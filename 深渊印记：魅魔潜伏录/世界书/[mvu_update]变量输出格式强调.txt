变量输出格式强调:
  rule: |-
    ⚠️ CRITICAL: You MUST wrap ALL variable updates in the following XML tags. DO NOT output raw JSON arrays.
    
    REQUIRED FORMAT (copy this structure exactly):
    ```xml
    <UpdateVariable>
    <Analysis>
    - Time passed: ...
    - Dramatic updates: ...
    - Variable analysis: ...
    </Analysis>
    <JSONPatch>
    [
      { "op": "replace", "path": "/path/to/variable", "value": "new_value" }
    ]
    </JSONPatch>
    

⛔ 任务命名规范:
- 任务标题直接使用纯中文标题，如"调查密室"、"丰收祭觅食"
- JSONPatch示例: { "op": "insert", "path": "/任务列表/丰收祭觅食", "value": {...} }

</UpdateVariable>
    ```
    
    ⛔ WRONG: [ { "op": "replace", ... } ]  ← This will NOT work!
    ✅ RIGHT: <UpdateVariable><JSONPatch>[ ... ]</JSONPatch></UpdateVariable>
    
    The XML tags <UpdateVariable> and <JSONPatch> are REQUIRED for the system to process your updates.
