变量输出格式:
  rule:
    - you must output the update analysis and the actual update commands at once in the end of the next reply
    - ⛔ 必须在回复的最末尾生成<UpdateVariable>，绝对禁止在回复开头生成
    - the update commands works like the **JSON Patch (RFC 6902)** standard, must be a valid JSON array containing operation objects, but supports the following operations instead:
      - replace: replace the value of existing paths
      - delta: update the value of existing number paths by a delta value
      - insert: insert new items into an object or array (using `-` as array index intends appending to the end)
      - remove
      - move
    - don't update field names starts with `_` as they are readonly, such as `_变量`
    - ⚠️ CRITICAL: you MUST proactively expand 技能树/可解锁技能 AND 道具商店/商品目录 when NEEDED, but ONLY when the current counts are below thresholds:
      - 技能树/可解锁技能: Only generate new skills if current count < 3
      - 道具商店/商品目录: Only generate new items if current count < 5
      - 任务列表: Only generate new tasks if (待接取 tasks + 进行中 tasks) count < 3
    - ⛔ DO NOT generate new skills/items/tasks if the respective lists already have enough options
    - Exception: Milestone events (level up, completed A/S rank tasks, new region) can bypass these limits
    - ⚠️ 当剧情中出现以下场景时，必须优先扩展商店与技能：酒馆闲聊、集市闲逛、NPC委托、日常对话、夜间探索。这些场景是引入新选项的最佳时机。
  format: |-
    <UpdateVariable>
    <Analysis>$(IN ENGLISH, no more than 80 words)
    - ${calculate time passed: ...}
    - ${check calendar events: ...}
    - ${decide whether dramatic updates are allowed: yes/no}
    - ${CONSUMABLE vs DURABLE CHECK: when using items, only decrement the 数量 of 消耗品 (consumables). 耐用品 (durables) always have 数量=1 and must never be decremented. If a durable is damaged/lost, use op:replace to set 数量 to 0 (UI will mark it as broken/lost).}
    - ${analyze every variable based on its check rules: ...}
    - ${SHOP & SKILL CHECK: Check current counts BEFORE generating. Skills: generate only if 可解锁技能 count < 3. Shop: generate only if 商品目录 count < 5. Tasks: generate only if (待接取 tasks + 进行中 tasks) count < 3. Skip generation if thresholds are met, unless it's a milestone event.}
    </Analysis>
    <JSONPatch>
    [
      { "op": "replace", "path": "${/path/to/variable}", "value": "${new_value}" },
      { "op": "delta", "path": "${/path/to/number/variable}", "value": "${positive_or_negative_delta}" },
      { "op": "insert", "path": "${/path/to/object/new_key}", "value": "${new_value}" },
      { "op": "insert", "path": "${/path/to/array/-}", "value": "${new_value}" },
      { "op": "remove", "path": "${/path/to/object/key}" },
      { "op": "remove", "path": "${/path/to/array/0}" },
      { "op": "move", "from": "${/path/to/variable}", "to": "${/path/to/another/path}" },
      ...
    ]
    </JSONPatch>
    

⛔ 任务命名规范:
- 任务标题直接使用纯中文标题，如"调查密室"、"丰收祭觅食"
- JSONPatch示例: { "op": "insert", "path": "/任务列表/丰收祭觅食", "value": {...} }
